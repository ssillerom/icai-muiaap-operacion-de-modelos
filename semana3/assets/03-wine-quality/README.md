# Datos de inferencia — Wine Quality

`inference_samples.csv` contiene cinco filas sin etiqueta para la práctica de
inferencia. Proceden de *Red Wine Quality (UCI)* en Kaggle y se han renombrado
las columnas a `snake_case`; se ha eliminado la columna objetivo `quality`.

- Fuente: <https://www.kaggle.com/datasets/uciml/red-wine-quality-cortez-et-al-2009>
- Referencia: P. Cortez et al., *Modeling wine preferences by data mining from
  physicochemical properties*, Decision Support Systems, 47(4), 2009.
- Licencia y atribución: deben respetarse las condiciones indicadas en la ficha
  de Kaggle al redistribuir datos más allá de esta muestra docente.

El archivo completo se usa únicamente para que el profesorado genere el
artefacto local `models/wine_quality_classifier.joblib`. Ese artefacto y los
datos de entrenamiento no se versionan en Git.
