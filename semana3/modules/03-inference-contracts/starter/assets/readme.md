# Datos de práctica

`inference_samples.csv` contiene cinco muestras de vino tinto preparadas para
inferencia. Su origen y atribución están en
[`../../../../../../../../assets/03-wine-quality/README.md`](../../../../../../../../assets/03-wine-quality/README.md).

La columna `sample_id` identifica la solicitud; las otras once columnas son el
contrato de entrada. No añadáis la etiqueta de calidad: el objetivo es inferirla
con el modelo ya entrenado.
