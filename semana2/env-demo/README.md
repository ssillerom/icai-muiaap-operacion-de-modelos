Como configurar y ejecutar:

Asegurar que estamos en semana2/env-demo
Si no es así, hacer: cd semana2/env-demo

Una vez en la carpeta adecuada, hacer: uv sync. Las dependencias se instalaran junto al entorno virtual

Para ejecutar main: python .\src\env_demo\main.py
Para ejecutar test: python .\src\env_demo\test\test_main.py
